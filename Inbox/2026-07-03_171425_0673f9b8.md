贵州阿格装配式建筑智造有限公司

设计流程管理文件（AI 辅助工作流）

文件编号：AG-DES-FP-001

版本：V1.0

生效日期：2025年

编制部门：技术部

适用范围：贵州阿格装配式建筑智造有限公司设计业务线

目录

右键目录，选择「更新域」刷新页码。

1. 目的

为规范业务板块设计需求从接收到最终成果交付的全流程，明确各环节的输入、输出、责任人及工具平台，压缩无效往返，保证设计质量与效率。

2. 流程总览（8 阶段）

流程总工期：约 8.5 个工作日（含并行压缩空间）。

3. 各阶段细则

3.1 P0 业务输入

输入：《设计需求信息表》（业务板块填写，含项目类型、面积、功能分区、风格倾向、预算区间、交付日期等）。

输出：经确认的《设计需求信息表》签字版（扫描件或电子签）。

责任人：业务板块填报，设计负责人审核。

质量要求：信息表字段缺项率 = 0；预算与面积数据须有来源依据。

3.2 P1 AI 初规（Kimi 初步方案规划）

输入：P0 签字版《设计需求信息表》。

输出：《初步方案规划》（Markdown / Word），含：功能分区逻辑、空间流线建议、风格关键词、技术可行性提示、陶粒墙板应用节点。

责任人：Kimi（AI 辅助）+ 设计负责人审核。

工具：Kimi 桌面版，调用阿格知识库（nomic-embed-text 嵌入）。

操作要点：将信息表内容整理为结构化提示词输入 Kimi；明确引用知识库原文，禁止通用知识填补；输出须包含 3 套差异化方向供 P2 筛选。

质量门控：设计负责人审核《初步方案规划》是否与需求表一致，不一致退回 P0 补录。

3.3 P2 设计补完（设计师补充完善）

输入：P1《初步方案规划》。

输出：《结构完善方案》，含：选定方向、空间尺寸细化、结构体系说明（含陶粒墙板节点）、机电点位初排。

责任人：主案设计师。

质量要求：结构完善方案须满足现行规范（GB 50033 等）；陶粒墙板应用节点须与阿格产品标准图集一致。

门控：设计负责人组织 15 min 快速评审，通过即进入 P3。

3.4 P3 AI 造像（阿里 z_image）

输入：P2《结构完善方案》+ 风格关键词。

输出：《意向方案图》≥ 3 张（正面透视、鸟瞰、室内主视角各 1 张）。

责任人：设计师操作，主案设计师筛选定案。

工具：阿里 z_image（造像 LLM）。

操作要点：将 P2 方案转化为 z_image 提示词（含空间尺度、材质关键词、光影方向）；同批生成 ≥ 3 张，设计师筛选 1 张作为后续基准；输出图分辨率 ≥ 1024×1024，存为 PNG。

质量门控：主案设计师确认意向图与 P2 空间结构无偏差，偏差退回 P2 修正。

3.5 P4 平面与体块

输入：P3 选定的《意向方案图》+ P2《结构完善方案》。

输出：《平面布置图》（含家具布置、动线、门窗洞口定位）；《体块模型》（SketchUp / Revit，含主要空间体量）。

责任人：主案设计师。

工具：AutoCAD / 天正、SketchUp / Revit。

操作要点：平面布置须标注陶粒墙板规格型号（如 90 mm、120 mm 板）；体块模型仅表达主要空间关系，不深入细部；平面与体块须互相校验，尺寸闭合。

质量门控：尺寸闭合检查（误差 ≤ 5 mm）；动线无死胡同；主案设计师签字。

3.6 P5 方案图纸

输入：P4《平面布置图》+《体块模型》。

输出：《平面布局方案图纸》正式版（含封面、设计说明、平面图、分析图、指标表）。

责任人：主案设计师 + 绘图员。

操作要点：图纸比例统一为 1:100（或 1:50），图框采用 AG-A3-001 标准；设计说明须包含陶粒墙板技术参数引用（LC25 强度等级、干密度 ≤ 1000 kg/m³ 等）；指标表须含：建筑面积、使用面积、墙板用量估算。

门控：设计负责人审核图纸完整性，缺项退回补图。

3.7 P6 材质定案

输入：P5《平面布局方案图纸》+ P4《体块模型》。

输出：《材质与造型方案》（含材质样板编号、色彩参数、节点示意）。

责任人：主案设计师 + 材料专员。

操作要点：外立面/室内主要材质须对应 RunningHub 工作流可调用素材库；陶粒墙板表面处理方式（清水、涂料、面砖）须明确；造型方案以照片级参考图 + 材质说明形式输出，不做大模型。

门控：材质与预算区间匹配（由业务板块确认）。

3.8 P7 最终成像（RunningHub）

输入：P6《材质与造型方案》+ P5 图纸 + P4 体块模型。

输出：《最终成像图》（高清，≥ 1920×1080，PNG 格式）。

责任人：设计师操作，主案设计师验收。

工具：RunningHub 云端 ComfyUI 工作流。

操作要点：将 P6 材质方案、P5 平面控制、P4 体块关系转化为 ComfyUI 工作流输入；工作流参数锁定：种子值、分辨率、LoRA 模型版本须记录存档；输出至少 2 个视角（外观日景 + 室内主视角），必要时补充夜景 1 张。

质量门控：成像与 P6 材质方案一致率 ≥ 90 %；无穿模、比例失真、材质错误；主案设计师验收签字。

3.9 P8 排版输出（Kimi 最终排版）

输入：P1 构思文件 + P5 平面图纸 + P7 最终成像图。

输出：《最终成果册》（PDF，A3 横版，含封面、目录、设计说明、图纸、效果图）。

责任人：Kimi（AI 辅助排版）+ 设计负责人终审。

工具：Kimi 桌面版。

操作要点：将上述三类文件统一导入 Kimi，按标准模板结构输出；排版风格统一为阿格企业 VI（字体：思源黑体，主色：AG-BLUE #0057B8）；页眉含项目编号 + 阶段标识，页脚含页码 + 出图日期。

质量门控：成果册页码连续、目录可跳转；图纸清晰度 ≥ 300 dpi；设计负责人终审签字后即为定稿，禁止无记录修改。

4. 并行与压缩规则

1. P1（AI 初规）与 P0（需求确认）可部分并行：需求表确认 60 % 内容后即可启动 P1，剩余字段后续补录。

2. P3（AI 造像）与 P4（平面体块）可压缩：若 P2 方案足够明确，P3 与 P4 可同时启动，以 P3 结果校验 P4 空间比例。

3. P7（最终成像）须等待 P6 材质定案全部完成，不可提前。

5. 文件命名与存档规则

版本号：V1.0 为初稿，每次重大修订 +0.1，终审通过为 VF（Final）。

存档：全部文件同步至百度网盘 AKO_Hub 项目目录，本地留备份。

6. 责任矩阵（RACI）

R = 执行（Responsible）  A = 负责（Accountable）  C = 咨询（Consulted）  I = 知情（Informed）

7. 异常与退回机制

8. 附则

1. 本文件由技术部编制，经设计负责人批准后生效，每半年复审一次。

2. 工具平台（Kimi、z_image、RunningHub）版本升级或接口变更时，须同步更新操作要点。

3. 所有阶段签字确认采用电子签名（微信企业号审批流），签字记录存档不少于 3 年。
